# 轻巧跳跃预览（2026-11-10）

按桌面跑酷分镜收小动作：0.18 秒预蹲、渐变收腿与摆臂、0.32 秒落地缓冲；双腿略错开，落稳再转正。

- 每次普通跳跃最多向上 180、向下 300、横向 240 像素（随桌面 scale 缩放）。只选当前可达平台，够不到就换目标；不包含完整多平台寻路。返回任务栏允许较长的向下落差。
- 抛物线最高点只比较高端点高 18–32 像素，并预留头顶空间。
- 起跳前、落地时重新检查目标；落地目标立即消费，进入独立缓冲状态后执行坐/躺/待机。6×4 像素内视为已经到达，不再原地起跳。失效平台暂避 6 秒。
- 拖拽、召回、平台消失时清除跳跃附加姿势。没有更改模型、材质或场景。

## 验证与打包

使用 Unity **6000.3.28f1**。菜单 `Kiko/8a 检查轻巧跳跃轨迹` 跑 45 组轨迹和到达/高度边界检查。
菜单 `Kiko/8b 打包轻巧跳跃预览（当前构建场景）` 使用 Build Settings 当前启用的场景，输出 `Builds/HopPreview/ZhixuFox.exe`，不会覆盖原有 Builds/ZhixuFox。

检查步骤：
1. 留一个较低窗口或桌面图标，右键选择坐下，观察预蹲、空中手臂、落地缓冲。
2. 让她到达并坐好，确认没有连续原地跳。
3. 起跳时移动/最小化目标窗口，应取消目标并落下，而不是瞬移追随。
4. 空中拖拽或召回，回到站姿后不应残留收腿。
5. 测试两套身材/服装，检查手臂与裙摆。高窗口无可达落脚点时不会强行跳上去。
